# E-Commerce Sales Data ETL Dashboard Project

An end-to-end ETL (Extract, Transform, Load) project built using Python, SQL Server, and Power BI to process and analyze e-commerce sales data.

This project demonstrates how raw business data can be cleaned, transformed, stored, and visualized for decision-making and reporting.

---

# Project Overview

The goal of this project is to create a complete ETL pipeline for e-commerce sales data.

## Workflow Includes
- Extracting raw sales data from files/databases
- Cleaning and transforming the data using Python
- Loading processed data into SQL Server
- Creating dashboards and reports in Power BI

This project helps in understanding real-world data engineering and analytics workflows used in companies.

# ETL Workflow

## 1. Extract
- Imported raw e-commerce sales datasets
- Read data using Python and Pandas

## 2. Transform
- Cleaned inconsistent data
- Removed duplicates
- Handled null values
- Converted data types
- Generated useful business metrics

## 3. Load
- Loaded transformed data into SQL Server
- Connected SQL Server data with Power BI
